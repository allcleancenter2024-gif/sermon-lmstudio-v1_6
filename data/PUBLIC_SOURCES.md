# 공개 성경 데이터 권장 출처

프로그램은 본문 자체와 라이선스 메타데이터를 함께 저장합니다. 아래는 2026-08-08에 공식 페이지에서 사용조건을 확인한 우선 연결 대상입니다.

| 자료 | 용도 | 사용조건 | 공식 출처 |
|---|---|---|---|
| World English Bible (WEB) | 영어 번역 | Public Domain. 변경한 본문은 WEB이라는 이름으로 부르지 않아야 함 | https://ebible.org/bible/details.php?id=engwebp |
| Westminster Leningrad Codex (WLC) text | 구약 히브리어 | 본문 Public Domain | https://hb.openscriptures.org/ |
| Open Scriptures Hebrew Bible lemma/morphology | 히브리어 어형·형태 분석 | CC BY 4.0, Open Scriptures Hebrew Bible Project 표시 | https://hb.openscriptures.org/ |
| SBL Greek New Testament (SBLGNT) | 신약 헬라어 | CC BY 4.0 | https://sblgnt.com/download/ |

개역개정과 쉬운성경은 이 프로젝트에 임의로 포함하지 않습니다. 정식 사용 허가를 받은 데이터가 있을 경우 `license_note`에 허가 정보를 기록하여 Import 하십시오.
