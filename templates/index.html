01

SBLGNT · 헬라어 본문

신약 원문의 기준 자료

저장: data/bible/greek/sblgnt/books/*.xml

사용: 중심본문의 헬라어 원문을 확인하고 번역문과 비교합니다. 성경 참조가 실제 본문과 연결되는지 검증하는 기준입니다.

사용 방법 · 성경 참조 입력 후 원문·형태론 조회를 누르세요.

02

MorphGNT · 형태론

lemma와 단어별 문법 정보

저장: 원본 data/bible/greek_nt/morphgnt/raw/ · 검색 DB greek_nt_tokens

사용: 표면형·lemma·품사·시제·태·법·격·수·성 등을 조회합니다. lemma 전체 검색으로 출현 위치를 찾을 수 있습니다.

사용 방법 · 구절을 조회하거나 lemma를 입력해 lemma 출현 검색을 누르세요.

03

Apparatus · 본문비평

이문과 사본 참고 자료

저장: data/bible/greek/sblgnt/apparatus/*.xml · textual_variants

사용: 특정 절의 이문·독법·사본 note를 참고합니다. 확정 본문이나 설교 근거를 자동으로 변경하지 않습니다.

사용 방법 · 성경 참조 입력 후 본문비평 조회를 누르고 목회자가 직접 검토하세요.

04

원어 근거 등록

설교 생성에 연결할 자료

저장: SQLite original_word_notes · 표면형/토큰 독음 original_pronunciations

사용: 출처·사용조건·lemma·뜻·형태가 있는 자료만 특정 절의 원어 근거로 연결합니다. 중심본문 전체 절의 연결상태도 점검합니다. 히브리어·헬라어는 원문 표면형과 발음기호가 있는 학술식 로마자 독음 안내를 함께 보여 줍니다.

사용 방법 · 자동 설치 또는 파일 확인 → 출처·사용조건 확인 → 내 PC DB에 등록 → 원문·독음 확인 → 설교 반영 전 목회자 검토 순서입니다. 독음은 참고용이며 원어 사전·문법 검토를 대체하지 않습니다.

PRACTICE FLOW · JHN 8:32

예시 본문으로 3분 실습

요한복음 8:32를 예시로 원문 확인부터 원어 근거 연결상태 점검까지 연습합니다. 버튼은 해당 입력란을 채운 뒤 관련 화면으로 이동합니다.

JHN 8:32
1본문 확인

SBLGNT 원문과 MorphGNT token을 읽기 전용으로 확인합니다.

2lemma 찾기

조회 결과의 lemma를 확인하고 전체 출현 위치를 검색합니다.

3근거 점검

등록 자료가 본문의 모든 절에 연결되는지 확인합니다.

권장 작업 순서와 주의사항
  1. 공식 원어 자료 자동 설치를 실행합니다. 이미 같은 자료가 있으면 중복 저장하지 않습니다.
  2. 중심본문을 입력하고 SBLGNT 원문과 MorphGNT 형태론을 읽기 전용으로 확인합니다.
  3. 설교에 원어 근거를 사용할 경우 출처와 사용조건을 확인한 뒤 등록하고 원어 연결상태 점검을 실행합니다.
  4. Apparatus note는 이문 참고용이며 확정 본문이나 설교 근거로 자동 승격되지 않습니다.
  5. “원어 근거 없음” 또는 “확인 필요”가 나오면 AI의 기억으로 보완하지 말고 자료와 목회자 검토를 먼저 보완합니다.

원본 파일·DB 자료·checksum·출처 기록은 분리 보존되며, 외부 Notebook 연구자료도 성경·원어 DB에 자동 합쳐지지 않습니다.

PRACTICE FLOW · ISA 41:10

구약 히브리어 실습

OSHB가 등록된 경우 히브리어 원어 연결을 확인하는 흐름입니다. 자료가 없으면 자동 보완하지 않고 상태를 안내합니다.

ISA 41:10
1히브리어 본문 준비

OSHB 파일을 선택하고 출처·사용조건을 확인합니다.

2원어 근거 확인

등록된 lemma·뜻·형태가 해당 절에 연결되는지 확인합니다.

3설교 반영 전 검토

출처와 사용조건이 있는 근거만 설교 생성 전에 사용합니다.

처음 실행

5분 준비
  1. LM Studio에서 로컬 서버를 시작합니다.
  2. 주소는 http://127.0.0.1:12345/v1로 둡니다.
  3. 프로젝트 폴더의 start.bat를 실행합니다.
  4. 로그인 후 상단 연결·모델·성경 DB 상태를 확인합니다.

설교 작성

화면 순서
  1. 설교 입력에서 주제·중심본문·시간을 입력합니다.
  2. 본문 연구에서 성경·번역·원어 근거를 확인합니다.
  3. 구조·생성에서 Preflight 후 초안을 생성합니다.
  4. 결과·근거를 검토하고 승인 후 저장·출력합니다.

문제 발생 시

안전한 복구
  1. 준비진단에서 연결과 DB를 다시 확인합니다.
  2. 최근 변경사항을 변경사항 안내에서 확인합니다.
  3. PowerShell에서 .\scripts\restore_known_good.ps1로 먼저 미리보기합니다.
  4. 확인 후 -Apply를 붙이면 현재 기준 커밋으로 추적 파일을 복구합니다.

복구 도구는 사용자 DB·백업·출력물·원어 파일을 삭제하지 않습니다.

초보자용 안전 체크리스트
  • LM Studio는 외부 공개 주소가 아닌 127.0.0.1 로컬 주소만 사용합니다.
  • 원어의 히브리어·헬라어 표기와 발음기호는 참고용이며 목회자 검토가 필요합니다.
  • 중심본문이 DB에 없거나 근거 검증이 실패하면 생성을 진행하지 않습니다.
  • 백업·복구 전에는 현재 작업 중인 설교를 저장합니다.
  • 상세 문서는 프로젝트의 docs/INSTALLATION_AND_OPERATIONS_GUIDE.md에서 확인합니다.

사용권을 확인한 원어 형태론 자료를 프로그램 공통 형식으로 등록합니다. V40는 MorphGNT TXT, OSHB 책별 XML과 전체 ZIP을 직접 변환하고 본문별 연결상태를 검증합니다.

MorphGNT: 신약 책별 *-morphgnt.txt를 그대로 선택 · OSHB: 공식 배포 ZIP을 압축 풀지 않고 그대로 선택할 수 있으며, 기존처럼 wlc 폴더의 책별 XML도 지원합니다. JSON/CSV/TSV는 필수 열 reference, language, lemma, 선택 열 transliteration, gloss, morphology.

원어 자료를 어디서 받고 어떻게 넣나요?
  1. 신약: MorphGNT SBLGNT 공식 저장소에서 필요한 책의 *-morphgnt.txt를 내려받습니다. 마태복음은 61-Mt-morphgnt.txt입니다.
  2. 구약: OSHB 공식 Releases의 전체 배포 ZIP(예: OSHB-v.2.2.zip)을 내려받고 압축을 풀지 않은 채 선택합니다.
  3. 파일 형식은 자동 감지로 두거나 MorphGNT/OSHB를 직접 선택하고 원어 파일 검사 · 미리보기를 누릅니다.
  4. 자료 출처·사용조건을 확인하고 체크한 뒤 검사한 원어 근거 DB 등록을 누릅니다. 등록 후 위의 원어 연결상태 점검으로 중심본문의 절별 연결을 확인합니다.

원어 사전 · lemma 뜻/음역 연결

MorphGNT/OSHB 원문을 바꾸지 않고 별도 사전 DB에서 정확히 일치하는 lemma의 뜻과 음역만 보강합니다. V40는 잘못 넣은 MorphGNT/OSHB 자료도 원어 근거로 자동 분류합니다.

V40

여기는 뜻 사전 전용입니다. 공식 strongsgreek.xml과 HebrewStrong.xml은 그대로 검사할 수 있습니다. 직접 만든 JSON/CSV/TSV의 필수 열은 language, lemma, gloss, 선택 열은 transliteration입니다. MorphGNT TXT나 OSHB ZIP/XML은 위의 원어 근거 가져오기로 자동 전달합니다. Strong 사전의 뜻은 영어이므로 한글 뜻이 필요하면 사용권을 확인한 한글 사전 CSV를 별도로 등록하세요.

lemma 뜻/음역 사전은 어디서 받고 어떻게 연결하나요?
  1. 신약: MorphGNT의 Strong Greek Dictionary XML에서 strongsgreek.xml을 받습니다.
  2. 구약: Open Scriptures HebrewLexicon에서 HebrewStrong.xml을 받습니다.
  3. 파일 형식을 자동 감지로 두고 파일 선택 → 사전 파일 검사 · 미리보기를 누릅니다.
  4. 공식 자료명과 실제 사용조건을 입력하고 확인란을 선택한 뒤 검사한 원어 사전 DB 등록을 누릅니다.
  5. 프로그램은 헬라어 철자와 히브리어 Strong 키를 원어 근거 DB의 lemma에 연결하며, 원문·형태 정보는 바꾸지 않습니다.
아직 검사한 원어 사전 파일이 없습니다.
