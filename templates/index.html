원어 근거 파일 일괄 가져오기

사용권을 확인한 원어 형태론 자료를 프로그램 공통 형식으로 등록합니다. V40는 MorphGNT TXT, OSHB 책별 XML과 전체 ZIP을 직접 변환하고 본문별 연결상태를 검증합니다.

V40

MorphGNT: 신약 책별 *-morphgnt.txt를 그대로 선택 · OSHB: 공식 배포 ZIP을 압축 풀지 않고 그대로 선택할 수 있으며, 기존처럼 wlc 폴더의 책별 XML도 지원합니다. JSON/CSV/TSV는 필수 열 reference, language, lemma, 선택 열 transliteration, gloss, morphology.

원어 자료를 어디서 받고 어떻게 넣나요?
  1. 신약: MorphGNT SBLGNT 공식 저장소에서 필요한 책의 *-morphgnt.txt를 내려받습니다. 마태복음은 61-Mt-morphgnt.txt입니다.
  2. 구약: OSHB 공식 Releases의 전체 배포 ZIP(예: OSHB-v.2.2.zip)을 내려받고 압축을 풀지 않은 채 선택합니다.
  3. 파일 형식은 자동 감지로 두거나 MorphGNT/OSHB를 직접 선택하고 원어 파일 검사 · 미리보기를 누릅니다.
  4. 자료 출처·사용조건을 확인하고 체크한 뒤 검사한 원어 근거 DB 등록을 누릅니다. 등록 후 위의 원어 연결상태 점검으로 중심본문의 절별 연결을 확인합니다.
아직 검사한 원어 근거 파일이 없습니다.
원어 자료 파일을 선택한 뒤 검사하세요.

원어 사전 · lemma 뜻/음역 연결

MorphGNT/OSHB 원문을 바꾸지 않고 별도 사전 DB에서 정확히 일치하는 lemma의 뜻과 음역만 보강합니다. V40는 잘못 넣은 MorphGNT/OSHB 자료도 원어 근거로 자동 분류합니다.

V40

여기는 뜻 사전 전용입니다. 공식 strongsgreek.xml과 HebrewStrong.xml은 그대로 검사할 수 있습니다. 직접 만든 JSON/CSV/TSV의 필수 열은 language, lemma, gloss, 선택 열은 transliteration입니다. MorphGNT TXT나 OSHB ZIP/XML은 위의 원어 근거 가져오기로 자동 전달합니다. Strong 사전의 뜻은 영어이므로 한글 뜻이 필요하면 사용권을 확인한 한글 사전 CSV를 별도로 등록하세요.

lemma 뜻/음역 사전은 어디서 받고 어떻게 연결하나요?
  1. 신약: MorphGNT의 Strong Greek Dictionary XML에서 strongsgreek.xml을 받습니다.
  2. 구약: Open Scriptures HebrewLexicon에서 HebrewStrong.xml을 받습니다.
  3. 파일 형식을 자동 감지로 두고 파일 선택 → 사전 파일 검사 · 미리보기를 누릅니다.
  4. 공식 자료명과 실제 사용조건을 입력하고 확인란을 선택한 뒤 검사한 원어 사전 DB 등록을 누릅니다.
  5. 프로그램은 헬라어 철자와 히브리어 Strong 키를 원어 근거 DB의 lemma에 연결하며, 원문·형태 정보는 바꾸지 않습니다.
아직 검사한 원어 사전 파일이 없습니다.
원어 사전을 등록하면 뜻이 비어 있는 lemma에만 자동 연결됩니다.
