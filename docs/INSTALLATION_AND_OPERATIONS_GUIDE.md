## 1. 전체 사용 흐름

```text
[LM Studio 실행] → [start.bat 실행] → [로그인]
        ↓
[준비상태 확인] → [주제·본문·시간 입력]
        ↓
[본문 연구 / 번역·원어 확인] → [구조·생성]
        ↓
[근거 검증] → [목회자 검토·승인] → [저장·출력]
```

## 2. 처음 실행하는 방법

1. LM Studio를 설치하고 로컬 서버를 시작합니다.
2. 기본 주소가 `http://127.0.0.1:12345/v1`인지 확인합니다.
3. 프로젝트 폴더에서 `start.bat`를 실행합니다.
4. 로그인합니다. 첫 실행이면 초기 관리자 계정을 만듭니다.
5. 화면 상단의 LM Studio 연결·생성 모델·성경 DB 상태를 확인합니다.
6. `설교 입력`에서 주제와 중심본문을 입력합니다.

LM Studio는 외부에 공개하지 않고 로컬 주소로만 사용합니다. `0.0.0.0`으로 변경하지 마세요.

## 3. 설교시간과 모델

`설교시간`에서 15·20·25·30분을 선택하면 READY 상태인 모델 중 권장 모델이 자동 선택됩니다. 모델 ID 뒤에 `:2` 같은 버전이 붙어 있어도 같은 기본 모델로 인식합니다.

- 15·20분: Qwen3.5 9B 우선
- 25·30분: Qwen3.5 27B 우선, 없으면 Qwen3.5 9B, 그 다음 Qwen3 8B
- 사용자가 모델 목록을 직접 고르면 수동 선택으로 고정됩니다.
- 설교 생성에서는 추론(reasoning/thinking) 출력을 사용하지 않도록 제한합니다.

## 4. 원어 자료 사용

| 자료 | 역할 | 화면에서 확인할 위치 |
|---|---|---|
| SBLGNT | 신약 헬라어 본문 | 본문 연구 → 원문·형태론 |
| MorphGNT | lemma·품사·시제·태·법 등 형태론 | 본문 연구 → lemma 검색 |
| Apparatus | 이문·사본 참고 | 본문 연구 → 본문비평 |
| OSHB | 구약 히브리어 본문·형태 정보 | 원어 자료 간편 등록 |
| 원어 근거 DB | 설교에 연결할 출처·뜻·형태 | 원어 연결상태 점검 |

히브리어와 헬라어는 원문과 발음기호가 있는 로마자 독음을 함께 표시할 수 있지만, 독음은 참고용입니다. 사전·문법서와 목회자 검토를 대체하지 않습니다.

```text
sermon-lmstudio-v1_6/
├─ app/                 핵심 로직·Provider·RAG·저장소
```

`data/`, `backups/`, `exports/`는 사용자 자료이므로 삭제하거나 GitHub에 올리기 전에 내용을 확인하세요.

## 6. 이상이 있을 때 정상상태로 복구

정상 기준 커밋 이후 파일이 변경되어 오류가 생긴 경우 PowerShell에서 다음을 실행합니다.

```powershell
.\scripts\restore_known_good.ps1
```

미리보기 확인 후 실제 복구는 다음처럼 명시적으로 실행합니다.

```powershell
.\scripts\restore_known_good.ps1 -Apply
```

실행 전 현재 변경사항을 `backups/recovery/`에 패치로 보존하고, Git이 추적하는 프로그램 파일만 마지막 정상 커밋(HEAD)으로 되돌립니다. 사용자 DB·백업·출력물·원어 파일은 삭제하지 않습니다.

## 7. 장애 대응 순서

1. `상태 다시 확인`을 누릅니다.
2. LM Studio 로컬 서버와 READY 모델을 확인합니다.
3. 중심본문이 성경 DB에 있는지 확인합니다.
4. 원어 자료가 없으면 AI 기억으로 보완하지 말고 자료를 먼저 등록합니다.
5. 설교 생성 전 Preflight를 실행합니다.
6. 생성 후 성경 근거·원어·분량·추론 태그 검사를 확인합니다.
7. 문제가 계속되면 `변경사항 안내`와 `작업 종합 대시보드`에서 버전·테스트 결과를 확인합니다.

## 8. 안전 원칙

- 기존 일반 RAG와 SQLite 데이터는 보존합니다.
- 외부 자료는 자동으로 확정 성경 근거가 되지 않습니다.
- 승인 전 초안은 다운로드·인쇄하지 않습니다.
- 원어 Apparatus는 참고자료이며 본문을 자동 변경하지 않습니다.
- Web Grounding 기본값은 OFF입니다.
