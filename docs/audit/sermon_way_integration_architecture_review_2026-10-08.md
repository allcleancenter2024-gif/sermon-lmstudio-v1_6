# 말씀길 통합 구조 점검

점검일: 2026-10-08  
대상 버전: `40.9.13`  
브랜치: `refactor/phase1-baseline-20260905`

## 판정

말씀길의 연구·작성 기능을 기존 설교 작성기에 모듈로 통합하는 방향이 적합하다. 기존 앱은 증거 기반 설교 작성, 버전 저장, 감사·검토·잠금, 출력의 재사용 가능한 경계를 이미 갖고 있다. 별도 앱을 유지하면서 브라우저 저장소나 iframe으로 인증·데이터를 공유하는 것은 적합하지 않다.

**현재 구조는 단일 로컬 사용자 환경에서는 통과하지만, 작업지시서가 요구하는 원격 다중 계정 협업의 운영 전환 기준은 아직 통과하지 못했다.** 아래 세 조건이 충족되기 전에는 통합 기능을 운영 사용자에게 개방하지 않는다.

1. 말씀길 실제 소스/API 및 운영 인증 경계 확인
2. 원고 소유자와 작성자·검토자·승인자 배정 모델 확정
3. 로컬 전용 앱과 원격 서비스 간 연결 토폴로지 확정

## 현재 구조와 작업지시서 대응

| 요구 | 기존 구현 | 판단 |
|---|---|---|
| 기존 설교와 버전 보존 | `sermons`, `sermon_versions` 및 immutable 버전 저장 | 재사용 가능 |
| 성경 본문·번역·원어·RAG | 기존 DB와 본문 연구 서비스 | 말씀길 외부 자료를 확정 성경 근거로 승격하지 않는 어댑터 필요 |
| 연구 구조 생성 | `StructureBuilder`가 기존 본문 연구를 호출, `sermon_sections`에 버전 저장 | 첫 연구 Section 연결 완료. 전체 설교 확장 기능은 아님 |
| 계정 인증 | 별도 SQLite의 사용자 계정, 프로세스 메모리 세션 | 같은 로컬 프로세스의 로그인 경계. 원격 웹 서비스의 SSO가 아님 |
| 원고 소유권 | `sermons`에 owner/user 필드 없음 | 계정별 접근 차단 불가 |
| 세 역할 협업 | 검토·승인 상태와 최종 잠금은 있으나 원고별 담당자 배정 없음 | 작성자·검토자·승인자 분리 보장 불가 |
| 검토 이력 주체 | 웹 요청의 검토자·잠금 담당자를 세션 계정으로 고정 | 이번 단계에서 사칭 경로 보완. 지정 역할 검사는 미구현 |
| 수정 및 충돌 | 새 설교 버전은 생성되지만 공유 revision의 `expectedRevision` 충돌 계약은 없음 | 동시 편집 통합 전 필요 |
| 최종 출력 | 무결성 검증된 잠금 버전을 기준으로 최종 패키지/HWPX 출력 | 재사용 가능. DOCX 등 각 포맷별 버전 선택 계약은 추가 대조 필요 |
| 서비스 네트워크 경계 | 앱 및 기본 LM Studio가 localhost 전용 | 보안에 적합하나 외부 말씀길 서버가 직접 호출할 수 없음 |

## 구조상 중단 조건과 처리

### 원고 소유권 부재

기존 계정은 원고 테이블과 연결되어 있지 않다. 과거 원고를 현재 로그인 계정에 자동 귀속시키면 소유자를 추측하는 데이터 이관이 된다. 이번 단계에서는 Research Section 저장본 조회를 관리자 전용으로 제한하고, 전체 원고 소유권 migration은 만들거나 운영 DB에 적용하지 않았다.

### 검토자 사칭 가능성

기존 검토·잠금 API는 클라이언트가 보낸 이름을 저장했다. API가 서버 세션에서 계정명을 확인해 기록하도록 수정했으며, 비로그인 요청은 거부한다. 과거에 자유 입력으로 저장된 검토자 이름은 소급 검증할 수 없다.

### 원격 서비스 경계 부재

앱은 `127.0.0.1`에서 실행되고 LM Studio도 localhost 기본 주소를 사용한다. 원격 사이트와 계정·DB를 공유하려고 로컬 앱이나 LM Studio를 `0.0.0.0`에 공개해서는 안 된다. 웹앱이 별도 서비스라면 인증·자료·모델을 중계하는 승인된 중앙 API가 필요하다.

### 말씀길 구현물 미확인

작업지시서에 기록된 말씀길 사이트와 실제 API 문서는 현재 검사 환경에서 확인되지 않았고, 제공된 폴더 및 인접 Bible_Speak 폴더에서도 별도 말씀길 소스를 찾지 못했다. 따라서 실제 요청/응답, 서비스 런타임, 사용자 식별자, 라이선스 metadata는 아직 대조하지 못했다.
